# Form-Saver-with-JavaScript

A front-end project that captures user input using JavaScript, validates the data, and displays it in a live HTML table. Built with vanilla JavaScript and Bootstrap, the form includes real-time input handling and DOM manipulation. No backend — all data is temporarily stored in memory and cleared dynamically.

# What I learn:

* DOM manipulation (document.querySelector, innerHTML)
* Event handling (onclick)
* Form validation (checking empty inputs)
* Dynamic HTML generation
* JavaScript logic for data display and clearing
